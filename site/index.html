Nostr Relay Bench

Every week, each actively developed Nostr relay is built from its latest release, loaded with the same million events on the same machine, and checked against the protocol. Capability is scored from each relay's code and docs.

Scoreboard

Performance is each relay against strfry on the same run (strfry = 100), across writing, reading, live delivery and connections. Correctness is the share of relay-tester's required checks passed with the relay as shipped. Click a column to sort and a relay for its details.

Performance by area

Each panel is the geometric mean of that area's tests, strfry = 100, on a log scale. A missing bar says why: not supported, refused by the relay's policy, or wrong answers (a fast wrong answer isn't counted).
