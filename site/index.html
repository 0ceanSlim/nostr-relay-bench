Nostr Relay Bench

Every week, each actively developed Nostr relay is built from its latest release, loaded with the same million events on the same machine, and checked against the protocol. Capability is scored from each relay's code and docs. Pick your relay above to see where it stands and what would move it most.

Scoreboard

Performance, correctness and capability

Performance is each relay against strfry in the same run (strfry = 100) across writing, reading, live delivery and connections. Correctness is the share of relay-tester's required checks passed by the relay as shipped. Capability is the weighted score out of 100. Click a column to sort and a row for the details.

Performance by area

Where each relay is fast, and where it isn't

Each panel is the geometric mean of that area's tests, strfry = 100, on a log scale. The four coloured areas make up the performance index; the grey ones are reported but left out of it. A missing bar says why: not supported, refused by the relay's policy, or wrong answers (a fast wrong answer isn't counted).

Capability

Eighteen criteria, weighted by what operators and clients need

Each relay scores 0 to 3 on each criterion (none, partial, good, best in class), times its weight. Hover a cell for the evidence behind it; click a relay's name to compare as it.
